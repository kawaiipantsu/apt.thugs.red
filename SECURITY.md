# Security reporting

Report vulnerabilities privately through the source repository's Security tab.
Do not put private keys, credentials, personal identifiers or private deployment
details into public issues. Review [the security model](docs/SECURITY.md) and
[production acceptance gates](docs/ROADMAP.md) before deployment.

This is a development release. It is not yet an accepted replacement for a
production archive. Public and private interfaces remain separated; HTTP
administration is closed pending the authentication milestone.
